# 0002 — Licenza do código

- Estado: **proposta, pendente de decisión da FGS**

## Opcións

**MIT**
- A favor: máxima reutilización; sen atrito para administracións, universidades e empresas; texto curto e coñecido.
- En contra: permite forks pechados, tamén servizos comerciais sobre o noso traballo sen devolver melloras.

**AGPL-3.0**
- A favor: quen ofreza un servizo en rede derivado ten que publicar o código; coherente con «nada se vende»; protexe o pipeline e os servizos en vivo, que é onde está o traballo.
- En contra: algunhas institucións e empresas evitan AGPL por política interna; menos reutilización de pezas soltas.

## Recomendación
AGPL-3.0 para todo o repositorio. Se a prioridade é que a Xunta ou outras entidades reutilicen pezas sen trámites, MIT.

Os datos (ODbL) e os textos (CC BY-NC-SA) teñen licenza propia e non dependen desta decisión.
